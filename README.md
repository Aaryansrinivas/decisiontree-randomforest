# Decision Trees and Random Forests

## Objective
To learn and implement tree-based machine learning algorithms for classification and understand ensemble learning techniques.

## Tools Used
- Python
- Pandas
- NumPy
- Matplotlib
- Scikit-learn

## Dataset
Heart Disease Dataset

## Steps Performed

1. Loaded and explored the dataset.
2. Split the dataset into training and testing sets.
3. Trained a Decision Tree Classifier.
4. Visualized the Decision Tree.
5. Analyzed overfitting by varying tree depth.
6. Trained a Random Forest Classifier.
7. Compared the performance of both models.
8. Calculated feature importance.
9. Evaluated the model using 5-Fold Cross Validation.

## Results

### Decision Tree
- Successfully trained and visualized.
- Performance depended on tree depth.
- Deep trees showed signs of overfitting.

### Random Forest
- Achieved better accuracy than a single Decision Tree.
- Reduced overfitting through ensemble learning.
- Produced more stable and reliable predictions.

## Feature Importance
Random Forest feature importance was used to identify the most influential features contributing to heart disease prediction.

## Cross Validation
5-Fold Cross Validation was performed to evaluate model robustness and generalization capability.

## Conclusion
Decision Trees are simple and easy to interpret but can overfit the training data. Random Forest overcomes this limitation by combining multiple decision trees using bagging, resulting in improved accuracy and better generalization. Therefore, Random Forest was the best-performing model for this task.
